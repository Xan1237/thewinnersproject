# The Winners Project

Experiments live in their own folders.

- [`robot/`](robot/README.md): Unitree G1 coffee pickup demo with Kimodo body motion, local object-contact IK, WASD control and a local HTTP API for LLM agents. Teammates run it without Modal access.

- [`bench/`](bench/README.md): Winnersbench, a local live leaderboard (Summerbench layout) over the arena results.

Credentials, local environments, and downloaded/generated assets are excluded from Git.
